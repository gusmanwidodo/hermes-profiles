# Creative Lead

One agent for brand, UX, marketing copy, and frontend. Built for a solo founder shipping a portfolio of small products, where splitting these into four agents costs more in coordination than it returns.

## What it does

| Domain | Scope |
|---|---|
| **Brand** | Logo and mark design, color systems, typography, voice, usage guidelines |
| **UX** | User flows, information architecture, journey mapping, usability critique, accessibility |
| **Copy** | Landing pages, in-product microcopy, positioning, messaging — written with the components, not after |
| **Frontend** | React / Next.js / Tailwind implementation, responsive behavior, design tokens, component work |

## What it does not do

Business strategy and pricing (CEO owns), backend, database, auth, payment logic, infrastructure and deploy. It hands those back rather than reaching into them.

## Quick start

As a Telegram bot (already configured):

```
@creative_a9max_bot design a logo for <product>
```

Locally:

```bash
hermes --profile creative-lead chat
```

## Skills

Required: `artifact-pyramids`, `brand-designer`, `ux-methodology`, `frontend-engineering`

Recommended: `go-to-market`, `copy-editor-methodology`, `seo-content-optimization`

Creative toolkit: `claude-design` (process, taste, anti-slop, surface-first), `popular-web-designs` (54 real design systems), `design-md` (token specs), `humanizer` (strip AI-isms from copy), `excalidraw`, `sketch`

## Output

- **Implementation** → working code in the repo + a report of what was actually verified
- **Exploration** → one self-contained HTML file with real options side by side and a recommendation
- **Documentation** → artifact pyramid, entry point `00-index.md`

## Principles worth knowing

Coherence beats polish. The surface archetype decides the composition, so a dashboard never gets a landing-page hero. Copy is design. No invented facts in marketing copy. Accessibility is part of done, not a later pass.
